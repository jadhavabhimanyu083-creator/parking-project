Complete System Capabilities

Everything Needed to Run Smart Parking Facilities

Built from the ground up to demonstrate practical applications of Data Structures and Algorithms in modern transportation infrastructure.

🗺️

2D Layout Designer & Painting

Design parking facilities in Step 2 with custom dimensions. Paint car slots, two-wheeler bays, driving aisles, entrance & exit gates, and EV charging facilities with LIFO Stack multi-action Undo.

Matrix 2D + LIFO Stack O(1)
⚡

Greedy BFS Shortest-Path Routing

Models plots as graph adjacency structures. BFS calculates shortest driving distances from Entrance gates to all compatible bays, greedily allocating optimal slots in real-time.

Graph BFS O(V + E)
🏢

Multi-Plot Facility Management

Create, edit, and configure multiple parking areas independently. Includes live tariff edits, grace period updates, and safe plot removal preventing accidental data loss when vehicles are parked.

Dynamic Vector Array + Hash Index
🚨

Dual Waiting Queue Manager

When capacity is full, vehicles enter a dual queue system. Emergency and VIP vehicles receive priority allocation, while regular drivers enqueue in a FIFO buffer with automatic checkout dequeue.

Priority Queue + FIFO Queue O(1)
🚗

Vehicle Check-In & Strict Validation

Enforces a mandatory 10-digit mobile number and official vehicle registration plate verification (e.g. DL01AB1234). Prevents duplicate entry using instant Hash Table lookups.

Hash Table (unordered_map) O(1)
💰

Automated Billing & Grace Period

Calculates parking duration and charges based on vehicle category (Car vs Two-Wheeler rates). Includes custom grace periods where short pick-up/drop-off visits are billed at zero cost.

Arithmetic Pricing Engine
🔔

Persistent Notification Bell Drawer

All system events, check-ins, check-outs, errors, and edits are stored in a dedicated notification drawer with an unread badge counter, timestamps, status color coding, and a Clear All option.

Persistent Event Storage
📅

Advance Slot Reservation

Reserve parking slots ahead of time with scheduled arrival windows. Reserved bays are locked on the visual grid and guarded against double-booking by regular walk-in arrivals.

State-Flag Guarding O(1)
📊

Audit Trail & Quicksort Analytics

Maintains complete historical vehicle records in a Doubly Linked List. Allows instantaneous multi-attribute sorting by entry timestamp, license plate (BST), or parking fee via Quicksort.

Doubly Linked List + Quicksort O(n log n)
🚪

Admin Gate Configuration & Map Scale

Full admin control over entrance, exit, and bidirectional gates with custom labels (Main Entrance, Gate 2, South Exit). Temporarily close or open routes, calibrate map scale in meters/cell, and run automated reachability validation.

Multi-Gate Graph Connectivity + Scale Metric
🛣️

Calibrated Route Distance & Driving Time

Accurately calculates traversable driving routes and distances in meters from configured entry gates to assigned bays. Computes realistic driving times at 15 km/h and warns administrators when bays are unreachable.

Shortest Path BFS / Dijkstra (Meters Calibration)
⚡

Smart EV Charging Facility & Allocation

Differentiates EV vehicles requiring charging from standard vehicles. Allocates nearest operational EV charger (CCS2, Type-2), skips broken stations, enqueues in dedicated EV waitlists when full, and produces itemized checkout bills.

EV Station State Guarding + Multi-Tier Allocation

Interactive Workflow

How ParkingFlow Operates in 3 Simple Steps

01

Configure Parking Area

Create or select a plot. Customize grid dimensions, hourly pricing for Cars and Two-Wheelers, and paint Driving Aisles, Entry Gates, and Exit Gates.

02

Check-in with Shortest Route

Drivers check in with their plate and 10-digit mobile number. The system executes BFS shortest-path routing and immediately reserves the nearest compatible bay.

03

Automated Exit & Queue Promotion

Vehicle checks out with duration tracking and grace period calculation. The freed bay is automatically re-allocated to any driver waiting in the priority queue!
